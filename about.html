Sobre o GameZone

O GameZone é um portal desenvolvido para quem ama o universo gamer. Nosso objetivo é ajudar jogadores a descobrir novos estilos de jogos e explorar diferentes experiências.

Através do nosso formulário, os visitantes podem compartilhar suas plataformas e gêneros favoritos.

Este projeto foi desenvolvido como atividade acadêmica de Programação Web, utilizando HTML, CSS e JavaScript.

Desenvolvido por Nicoly Ferreira Ricardo, estudante de Análise e Desenvolvimento de Sistemas, como atividade acadêmica da disciplina de Programação Web.
