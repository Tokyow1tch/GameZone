
# GameZone — Universo Gamer

Projeto acadêmico desenvolvido na disciplina de Programação Web da PUCPR.

O GameZone é um site voltado ao universo gamer, com identidade visual futurista em neon roxo e rosa.

## Acesse o projeto

[Visitar o GameZone](https://tokyow1tch.github.io/GameZone/)

## Funcionalidades

- Página inicial com conteúdo sobre o universo gamer.
- Navegação entre as páginas.
- Formulário com validação dos campos.
- Envio de informações pelo método GET.
- Recuperação e exibição dos dados com JavaScript.
- Página de apresentação do projeto.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

```text
GameZone/
├── index.html
├── form.html

├── about.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Aprendizados

Durante o desenvolvimento, pratiquei estruturação de páginas HTML, organização de arquivos, estilização com CSS, validação de formulários e manipulação de parâmetros da URL com JavaScript.
